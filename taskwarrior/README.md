# Taskwarrior

Taskwarrior as the list of what waits on whom: one config and one task database for both Macs in Dropbox, an `owner` field for me or a bot, projects named after PARA with lessons as `<project>.lesson`, the everyday commands with their output, and Tab completion that knows my projects, their keys, and each task's description.

- `lesson.tex`: the lesson.
- `slides.txt`: the same steps as a slideshow in a tmux pane, beside a shell pane. It runs with `slides.py` from my settings repo (`Scripts/slides/`): `python3 slides.py slides.txt <shell-pane-id>`.
