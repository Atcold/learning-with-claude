# Self-hosting

My music on my own server instead of Spotify. The lesson follows the pipeline in order: exporting the Spotify playlists, the music I already own, finding the rest with Lidarr, Soularr, and slskd, serving it with Navidrome to Cassette, and discovery with ListenBrainz and Explo. It ends with what runs where on AlfDROID.
