# Where should an app keep its files?

eink, the site my Mac serves to the e-ink tablet, needed somewhere to keep my data: the notes I add to a recipe while cooking. My home folder already holds 67 dot files and folders, one or more per program. This lesson looks at that clutter, at the convention that sorts it (the XDG Base Directory Specification: config, data, state, cache), at who on my Mac already follows it, and at what it means for eink.
