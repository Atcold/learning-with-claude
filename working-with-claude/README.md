# How I work with Claude

After a restructure of my notes, projects and Dropbox, Claude and I agreed on how I work with it: one home per project, rules in one place, the notes vault for what spans projects. This lesson is that agreement and the evidence behind it: where Claude keeps instructions and memory, why every project shared one memory, how Dropbox carries a folder of links, and the one-column bug in a completion list that a terminfo patch fixed.
