# AlfDROID

AlfDROID is a OnePlus 6 (8 GB + 128 GB) turned into an always-on server: plugged in behind the router with the screen off, Debian running inside Termux with proot-distro, reachable over the tailnet. The lesson lists the phone's specs, the setup path, the battery hazard of a phone kept charged, and the next steps from updating OxygenOS to a Debian shell over SSH.

- `lesson.tex`: the lesson.
